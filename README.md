# 🧠 Refactoring & Design Patterns Lab 
**📍 Repositorio de prácticas** basado en [refactoring.guru](https://refactoring.guru) | *Clean Code*, *SOLID* en Java.

---

## 🚀 **Contenido**
- ✅ Ejercicios de **refactorización** (code smells → soluciones).
- ✅ Implementación de **patrones de diseño** (GoF: Creacionales, Estructurales, Conductuales).
- ✅ Ejemplos con **principios SOLID** y buenas prácticas.
- ✅ Proyectos modulares organizados por categorías.

---

## 🛠️ **Tecnologías**
- **Lenguaje**: Java 17 | Kotlin | [Otro] *(elige el tuyo)*
- **Herramientas**: IntelliJ IDEA | VS Code
- **Build**: Maven | Gradle *(opcional)*
- **Testing**: JUnit 5 | Mockito *(opcional)*

   ```bash
